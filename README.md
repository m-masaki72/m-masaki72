### MasakiMori

モバイルゲームの開発を本業にしているエンジニアです。仕事の外では、VST プラグイン、Windows の常駐アプリ、ブラウザで動く Web ツール、Alexa スキルなどを個人で作っています。

制作物と記事は [Mori Lab](https://morilab-garage.com/) にまとめています。

### 制作物

- [SANA 8BIT VST](https://morilab-garage.com/projects/sana-8bit-vst/) — DAW の中で 8bit の音を鳴らすシンセサイザー
- [Web Loudness Meter](https://morilab-garage.com/projects/web-loudness-meter/) — ブラウザで動く音量計測ツール（LUFS / dBFS / FFT）
- [デジタル照度計 LX-26](https://morilab-garage.com/projects/web-lux-meter/) — スマホのカメラで照度を測る Web アプリ
- [LESS, STILL. — 構造分解](https://morilab-garage.com/projects/structure-jenga/) — 部材を叩いて音を聴き、一本ずつ抜く3Dパズル
- [制作物の一覧](https://morilab-garage.com/projects/)
